## Key Information Added

### Assembly Capabilities Documented
- **Inline assembly**: `--assemble "mov rax, 0x42"` with architecture flags
- **File-based assembly**: `--assemble-file shellcode.s --assemble-output shellcode.bin`
- **Multi-architecture support**: x86, ARM, ARM64, MIPS with 16/32/64-bit modes
- **Machine code generation**: Direct conversion to binary output files

### Disassembly Capabilities Documented
- **Raw bytes disassembly**: `--disassemble-bytes "48c7c0..."` with arch flags
- **Section disassembly**: `--disassemble-section-raw .text` with custom arch
- **Address mapping**: `--disassemble-address 0x400000` for proper address display
- **Cross-architecture support**: Same architecture modes as assembly

### Usage Patterns Documented
```bash
# Assembly: Generate machine code
cumpyl --assemble "mov rax, 0x42" --assemble-arch x86 --assemble-mode 64

# Assembly from file: Create shellcode binaries
cumpyl --assemble-file code.s --assemble-arch arm64 --assemble-mode 64 --assemble-output shellcode.bin

# Disassembly: Convert hex to assembly
cumpyl --disassemble-bytes "48c7c042000000" --disassemble-arch x86 --disassemble-mode 64

# Cross-architecture: Multiple platform support
cumpyl --assemble "mov r0, #0x42" --assemble-arch arm --assemble-mode arm
```
