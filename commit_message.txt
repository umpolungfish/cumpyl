## Summary
Implements a comprehensive autonomous agent framework (AjintK integration) that provides specialized AI-powered agents for binary analysis, obfuscation planning, batch processing, quality assurance, reporting, and threat intelligence. The agents leverage LLMs (Claude, Gemini, DeepSeek, Qwen, Mistral) to provide intelligent analysis and recommendations.

## Core Changes

### 1. Cumpyl-Specific Tool Definitions (`AjintK/framework/cumpyl_tools.py`)
**Created 13 specialized tools that interface with cumpyl's CLI:**
- `analyze_binary`: Comprehensive binary analysis
- `suggest_obfuscation`: Get obfuscation recommendations
- `run_plugin`: Execute specific cumpyl plugins
- `list_plugins`: List available plugins
- `encode_section`: Encode binary sections
- `generate_report`: Generate analysis reports
- `hex_view`: View binary in hex format
- `batch_analyze`: Batch process multiple files
- `pe_string_obfuscate`: Apply string obfuscation
- `disassemble`: Disassemble binary code
- `validate_binary`: Validate binary integrity
- `compare_binaries`: Compare two binaries
- `extract_strings`: Extract readable strings

**Before:** No agent-accessible tools for cumpyl operations

## Agent Execution Modes

### Single Agent
```python
agent = BinaryAnalysisAgent(config)
result = await agent.run(task, context)
```

### Pipeline (Sequential)
```
Analysis → ThreatIntel → Reporting
```
Context flows between stages for comprehensive analysis.

### Swarm (Parallel)
Multiple agents analyze simultaneously for different perspectives.

## Technical Implementation

### Agent Architecture
- All agents inherit from `BaseAgent` with async LLM calls
- Tool executor interfaces with cumpyl CLI
- Context passing enables pipeline workflows
- Factory function `create_cumpyl_agent()` for easy instantiation

### Safety Features
- Section safety tiers (ADVANCED, INTERMEDIATE, BASIC, AVOID)
- QA validation after transformations
- Dry-run mode for obfuscation planning
- Binary comparison before/after modifications

### LLM Integration
- Multi-provider support (Anthropic, Google, DeepSeek, Qwen, Mistral)
- Intelligent routing based on task type
- Response caching for efficiency
- Configurable temperature and token limits

## Usage Examples

### Command Line
```bash
# Run example workflows
python AjintK/examples/cumpyl_workflows.py 1 /path/to/binary.exe  # Single agent
python AjintK/examples/cumpyl_workflows.py 2 /path/to/binary.exe  # Pipeline
python AjintK/examples/cumpyl_workflows.py 3 /path/to/binary.exe  # Swarm
```

### Python API
```python
from AjintK.framework import get_workflow_runner

runner = get_workflow_runner(config)
result = await runner.run_analysis_workflow("/path/to/binary.exe")
```
