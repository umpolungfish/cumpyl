fix: Resolve ConfigManager type mismatch in Batch CFG Extraction menu

## Summary
Fixed "argument of type 'ConfigManager' is not iterable" error that occurred when using the Batch CFG Extraction menu (option 4 in the start menu). The error was caused by passing the framework's ConfigManager object where a plain dict was expected.

## Root Cause
Two different `ConfigManager` classes exist in the codebase:
1. `cumpyl_package/config.py` - Framework ConfigManager (holds config sections as attributes like `.performance`, `.framework`)
2. `plugins/config_manager.py` - Plugin ConfigManager (expects a plain dict, uses `in` operator on `self.config`)

When `batch_cfg_menu.py` passed the framework's ConfigManager to `CFGExtractorPlugin`, it was stored as `self.config` in the plugin's ConfigManager. The `validate()` method then failed on `if field not in self.config` because the framework's ConfigManager doesn't implement `__contains__`.

## Changes Made

### 1. `cumpyl_package/batch_cfg_menu.py`
**Before:**
```python
self.cfg_extractor = CFGExtractorPlugin(config if config else {})
```

**After:**
```python
plugin_config = {}
if config and hasattr(config, 'get_plugin_config'):
    plugin_config = config.get_plugin_config('cfg_extractor') or {}
elif isinstance(config, dict):
    plugin_config = config
self.cfg_extractor = CFGExtractorPlugin(plugin_config)
```

Now properly extracts a dict from the framework ConfigManager before passing to the plugin.

### 2. `cumpyl_package/batch_processor.py`
**Before:**
```python
def __init__(self, config: ConfigManager, output_dir: str = None):
    self.config = config
```

**After:**
```python
def __init__(self, config: ConfigManager = None, output_dir: str = None):
    if config is None:
        config = ConfigManager()
    self.config = config
```

Creates a default ConfigManager when `None` is passed, preventing AttributeError when accessing `.performance` attributes.
