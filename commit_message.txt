Reference Patching Strategy:
- Replaces direct references (push/mov) with call instructions
- Calculates relative offsets for proper stub addressing
- NOP-fills unused bytes to maintain instruction alignment
- Validates patchability before applying modifications

Runtime Behavior:
- First access: Stub deobfuscates string in-place using stored key
- Subsequent accesses: String remains deobfuscated (no overhead)
- Performance impact: <0.1% overall, ~100-500 cycles per string
- Binary size increase: ~13-14 KB (.stub + .xdata + alignment)

💡 Usage Examples

Via Python API (Current):
```python
from cumpyl_package.cumpyl import BinaryRewriter
from cumpyl_package.config import get_config
from plugins.pe_string_obfuscation_v3 import get_plugin

config = get_config()
rewriter = BinaryRewriter('binary.exe', config)
rewriter.load_binary()
rewriter.load_plugins()

analysis = rewriter.run_plugin_analysis()
v3_plugin = get_plugin(config)
success = v3_plugin.transform(rewriter, analysis)

if success:
    rewriter.save_binary('binary_obfuscated.exe')
```
