fix: Save obfuscated binary to disk after PE string transformation

Adds missing save operation after successful PE string obfuscation, ensuring
the modified binary is written to disk rather than only existing in memory.

## Problem

When using `--pe-string-obfuscate` from the Build-A-Binary menu or CLI:
- ✅ Analysis ran successfully
- ✅ Transformation completed successfully
- ❌ Modified binary was NEVER saved to disk
- ❌ Users received success messages but no output file

**Root Cause**: The transformation code modified the binary in memory but
lacked a `save_binary()` call to persist changes to disk.

**User Impact**: String obfuscation appeared broken - transformations seemed
to succeed but produced no output files.

## Solution

Added save operation after successful transformation (cumpyl.py:992-998):

```python
if success:
    console.print("[green]✓ PE string obfuscation transformation completed successfully[/green]")

    # Save the modified binary
    output_file = args.output or f"obfuscated_{os.path.basename(args.input)}"
    print(f"[*] Saving obfuscated binary to: {output_file}")
    if rewriter.save_binary(output_file):
        console.print(f"[green]✓ Binary saved successfully to: {output_file}[/green]")
    else:
        console.print(f"[red]❌ Failed to save binary to: {output_file}[/red]")
```
